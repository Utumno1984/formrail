Formrail Pro for teams

Record-edit integrity for business apps: never lose what a user typed, always show what is about to change, and keep their work when the record is updated on the server in the meantime.

Edit records without losing work

ERP screens, back-office tools and admin portals share one problem: people edit long records, often while someone else or a background job changes the same record. Formrail Pro covers that moment.

  • Change Summary

    Before saving, a readable list of every changed field with its label and the before and after value, computed against the saved record, never against a default.

    Change Summary Invoices example

  • Form Rebase

    When a newer version of the record arrives while the user is editing, fields they did not touch take the server value, fields changed on both sides keep the user's value and are listed as conflicts.

    Form rebase Rebase notice

  • Virtual List Report

    The List Report with virtualized rows for very large datasets. It keeps the props and state of the free List Report and behaves as the free table below a row threshold.

    Virtual List Report

The demo is free to explore and not for production use until the license terms are published.
