Formrail

Formerly react-object-page.

An open-core React design system for List Report and Object Page screens: lists with filters and bulk actions, sectioned editors with a sticky save bar and dirty-guard.

Browse the components (free, MIT) See the Pro preview

Install

npm install @formrail/core

React 18 or 19 is a peer dependency.

What makes it different

  • Two complete floorplans

    A List Report with filter pills, search and sortable columns that keeps the same footprint while loading, empty or full, and an Object Page with an anchor bar and a sticky save bar.

    List Report Object Page

  • Dirty-tracking against the saved baseline

    Editing a field marks the form dirty, typing the original value back makes it clean again, and a value hydrated from outside is never mistaken for a user gesture.

    DirtyGuard Validation recipe

  • Accessibility checked in CI

    Keyboard handling, focus management and ARIA are built into the components. Fields in a locked, forced or disabled state cannot be edited, from the keyboard either, and explain why through a real aria-describedby. The stories are covered by Playwright end-to-end tests and screenshot comparison at desktop, tablet and mobile sizes.
