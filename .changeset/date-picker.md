New `DatePicker`: a text input in the locale's numeric format (order and separator from `Intl.DateTimeFormat#formatToParts`, e.g. `MM/DD/YYYY` for `en-US`, `DD/MM/YYYY` for `it-IT`, shown as the placeholder) plus a button that opens the `Calendar` in a popover. The value is an ISO calendar date (`YYYY-MM-DD`) like the Calendar's. Typed text is committed when the focus leaves the input and on Enter (4-digit year; a pasted ISO date is accepted in every locale); an empty text gives `null`; a text that is not an acceptable date gives `onValueChange(null)` plus `onInvalidInput(text, reason)` (`'unparsable' | 'out-of-range' | 'disabled-date'`) and stays visible to be corrected. Alt+ArrowDown or the button open the calendar with the focus on the selected date (else today); picking closes it and returns the focus; Escape closes only the popover, also inside a Dialog or Sheet (popover level of the z-index scale). `Field` integration (`id`, descriptions, `aria-invalid`, `aria-required`, `name`, `data-rop-name`); `disabled` out of the tab order; `forced`/`locked` keep the focus but never open the calendar. No `onValueChange` echo on an external `value` or `locale` change. Exports `DatePicker`, `DatePickerProps`, `DatePickerLabels`, `DatePickerInvalidReason`, `DatePickerSize`.
