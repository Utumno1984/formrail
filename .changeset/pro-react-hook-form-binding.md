New entry `@formrail/pro/react-hook-form` (#507): `useReactHookFormBinding(form)` binds a React Hook Form form (`useForm()`) to the `RebaseFormBinding` contract, so `useChangeSummary` and `useFormRebase` of `@formrail/pro/engine` work on it without `@formrail/core`. `binding.values` and `binding.baseline` are immutable snapshots of the values React Hook Form mutates in place, with the same identity across renders that change no value; the baseline follows React Hook Form's defaults (`form.reset(data)`, the `values` prop) and is the object passed to `binding.reset(saved)`. A rebase is written with `reset(incoming)` then `reset(merged, { keepDefaultValues: true })`: no `type: 'change'` event, `dirtyFields` only on the user's edits, `touchedFields` and `submitCount` kept, the errors of the fields the rebase did not change kept. `isSaving` / `saveError` map `handleSubmit` (`isSubmitting`, a failed submit), or come from the options for a save of your own. `react-hook-form` (`^7.92.0`) is an **optional** peer dependency, used for the types only; the main entry `@formrail/pro` and `@formrail/pro/engine` do not name it. The package stays private.
